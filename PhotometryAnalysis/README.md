Photometry Analysis Code

Photometry analysis code for Ferrigno, Iliakis et al. (2026) "Indirect pathway neurons in the tail of the striatum regulate inhibitory control over sensory driven behavior".

MAIN ANALYSIS SCRIPTS:

eventAlignedTraces.m - Code used to generate peri-stim time histograms and relevant peak/AUC quantifications.

kernelGLM.m - Code used to conduct kernelGLM analysis. 


HELPER FUNCTIONS: 

PhotometryHelperFunctions folder contains a range of helper functions that the main analysis scripts depend upon.
