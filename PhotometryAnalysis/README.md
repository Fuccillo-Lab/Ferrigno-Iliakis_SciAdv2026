# Photometry Analysis Code

Photometry analysis code for Ferrigno, Iliakis et al. (2026) "Indirect pathway neurons in the tail of the striatum regulate inhibitory control over sensory driven behavior". We acknowledge the use of generative AI (ChatGPT 5.2, 5.3, 5.4, 5.5) as an auxiliary tool in the generation and optimization of this analysis code.

## Main Analysis Scripts

### eventAlignedTraces.m
Code used to generate peri-stim time histograms and relevant peak/AUC quantifications.

### kernelGLM.m
Code used to conduct kernelGLM analysis. 


## Helper Functions

PhotometryHelperFunctions folder contains a range of helper functions that the main analysis scripts depend upon.
